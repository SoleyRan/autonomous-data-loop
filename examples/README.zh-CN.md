# 示例目录

[English](README.md)

本目录存放自动驾驶数据闭环项目的脱敏公开示例。它们不是生产数据，也不代表任何内部系统。

## 已包含示例

| 目录 | 内容 |
|---|---|
| `metadata/` | MCAP 和数据集元数据示例 |
| `manifest/` | 数据包和数据集 manifest 示例 |
| `label-format/` | 统一标签格式示例 |
| `training/` | 训练配置、训练任务、指标和模型卡片示例 |
| `api/` | Mock API 定义 |
| `probe-rule/` | 探针规则示例 |

## 规则

示例应使用通用 ID、通用名称和模拟时间戳。不要包含真实车辆、设备、接口地址、路径、客户数据或凭据。
