# 文档目录

[English](README.md)

本目录用于存放自动驾驶数据闭环项目的中英文双语技术文档。

## 双语规则

所有公开文档都需要维护英文和中文两个版本：

- 英文：`README.md` 或 `*.md`
- 中文：`README.zh-CN.md` 或 `*.zh-CN.md`

新增文档时，请在同一目录下同步新增对应译文。

## 目录说明

| 目录 | 用途 |
|---|---|
| `00-overview/` | 项目背景、范围和整体价值 |
| `01-phase1-vehicle-cloud-upload/` | 阶段一车云数据回传与联调 |
| `02-phase2-auto-labeling-qc/` | 阶段二自动化标注、Xtreme1 质检与导出 |
| `03-phase3-dataset-training/` | 阶段三数据集管理 |
| `04-phase4-model-training/` | 阶段四模型训练闭环 |
| `05-phase5-auto-test-evaluation/` | 阶段五自动化测试与评测闭环 |
| `06-phase6-feedback-loop/` | 阶段六失败 case 回灌与定向采集 |
| `architecture/` | 总体架构、数据流和模块设计 |
| `ai-agent-workflow/` | AI Agent 辅助工程协作方式 |
| `roadmap/` | 长期路线图和分阶段交付计划 |
