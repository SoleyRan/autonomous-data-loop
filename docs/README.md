# Documentation

[简体中文](README.zh-CN.md)

This directory contains the bilingual technical documentation for the autonomous data loop project.

## Bilingual Rule

Every public document should have both English and Chinese versions:

- English: `README.md` or `*.md`
- Chinese: `README.zh-CN.md` or `*.zh-CN.md`

When adding a new document, add the paired translation in the same directory.
