# Phase 2: Automated Annotation and Quality Inspection

[简体中文](README.zh-CN.md)

Phase 2 turns uploaded MCAP data into usable labeled datasets through automated annotation, Xtreme1-based 3D quality inspection, label versioning, and multi-format export.

## Scope

- Company-side MCAP asset management.
- Platform filtering and playback.
- Automated annotation engineering deployment.
- Xtreme1 integration for 3D quality inspection and manual correction.
- Canonical label versioning.
- KITTI and nuScenes export.

## Status

Designed and ready for implementation.
