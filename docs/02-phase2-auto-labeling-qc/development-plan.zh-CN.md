# 开发计划

[English](development-plan.md)

## 建议工作流

| 工作流 | 主要负责人 | 输出 |
|---|---|---|
| MCAP 资产管理 | 后端 | 元数据表、筛选 API、回放入口 |
| 平台页面 | 前端 | MCAP 列表、标注任务页、质检任务页、导出页 |
| 自动化标注工程化 | 算法 / 工程 | 预处理脚本、标注 Worker、输出适配器 |
| Xtreme1 集成 | 后端 / 工程 | 任务适配层、导入导出映射、结果回收 |
| 标签与导出 | 后端 / 算法 | 统一标签存储、KITTI 导出、nuScenes 导出 |

## 推荐里程碑

| 里程碑 | 目标 |
|---|---|
| M1 | MCAP 资产可筛选和回放 |
| M2 | 自动化标注可生成草稿标签 |
| M3 | Xtreme1 可接收带草稿标签的质检任务 |
| M4 | 校准后的标签可回传平台并形成最终版本 |
| M5 | 最终标签可导出 KITTI 和 nuScenes |

## AI 辅助研发机会

这个阶段很适合使用 AI Agent 辅助工程开发：

- 生成数据库表和接口草案。
- 编写 Worker 脚本和部署模板。
- 实现格式转换示例。
- 生成前端页面骨架。
- 联调阶段分析日志。
- 生成发版说明和验收清单。

它的价值不只是加快编码，也能让文档、评审材料和交付物更加一致。
