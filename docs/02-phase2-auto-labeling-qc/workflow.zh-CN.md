# 业务流程

[English](workflow.md)

## 主流程

```mermaid
sequenceDiagram
  participant U as 用户
  participant P as 平台
  participant S as 存储
  participant A as 自动化标注 Worker
  participant X as Xtreme1
  participant E as 导出 Worker

  U->>P: 筛选并回放 MCAP 资产
  U->>P: 选择进入标注的数据
  P->>S: 创建标注输入缓存
  P->>A: 启动自动化标注
  A->>S: 读取 MCAP 派生输入
  A->>P: 保存草稿统一标签
  P->>X: 创建 3D 质检任务
  X->>U: 提供 3D 校准工作台
  U->>X: 修正框、类别和属性
  X->>P: 回传质检后标签
  P->>P: 校验并冻结最终标签
  U->>P: 请求 KITTI / nuScenes 导出
  P->>E: 启动导出任务
  E->>S: 生成导出包
```

## 步骤一：MCAP 筛选

用户在平台上查看已上传的 MCAP 资产。首期实现以整包 MCAP 作为选择单位。

建议筛选维度：

- 上传时间。
- 车辆或设备别名。
- 事件或探针类型。
- 持续时长。
- 数据包状态。
- 回放可用状态。

## 步骤二：自动化标注

平台创建标注任务，并准备自动化标注 Worker 需要的输入。Worker 执行推理后，将结果保存为内部统一标签格式。

草稿标签不是最终标签，而是一个可追溯的中间版本。

## 步骤三：Xtreme1 质检

平台创建对应的 Xtreme1 任务，并导入 3D 标注所需输入。质检人员在 Xtreme1 中检查并修正自动化标注结果。

典型修正包括：

- 移动或缩放 3D 框。
- 修正类别。
- 新增漏标目标。
- 删除误检目标。
- 修改属性。

## 步骤四：标签定稿

Xtreme1 结果回传平台后，平台对标签进行校验，保存最终版本，并在需要时冻结用于导出。

校验示例：

- 必填字段存在。
- 帧时间戳可以映射回 MCAP 数据。
- 类别属于受支持的标签体系。
- 3D 框尺寸处于合理范围。

## 步骤五：导出

导出服务读取最终统一标签并生成外部格式包。

首期公开格式：

- KITTI。
- nuScenes。

未来格式应通过新增适配器实现。
