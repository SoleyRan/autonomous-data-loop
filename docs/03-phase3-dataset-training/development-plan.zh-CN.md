# 开发计划

[English](development-plan.md)

## 建议工作流

| 工作流 | 输出 |
|---|---|
| 数据集实体模型 | 数据集、数据集版本、样本、划分、manifest、血缘表 |
| 样本索引构建 | 基于冻结标签和 MCAP 元数据构建可复用样本索引 |
| 数据集创建 API | 创建草稿数据集、添加筛选条件、生成版本 |
| 划分服务 | 生成确定性的 train/validation/test 划分 |
| 统计服务 | 产出类别、帧数、划分和场景统计 |
| Manifest 服务 | 为下游任务生成数据集 manifest |

## 推荐里程碑

| 里程碑 | 目标 |
|---|---|
| M1 | 可创建数据集版本实体和样本索引 |
| M2 | 可生成数据集划分和统计结果 |
| M3 | 可导出数据集 manifest，并被 demo 工具消费 |
| M4 | 数据集血缘可以追溯到 MCAP 和标签版本 |

## AI 辅助研发机会

- 生成数据库表和 migration 草案。
- 生成 manifest 构建器和校验器。
- 创建确定性划分脚本。
- 生成质量统计脚本。
- 生成 API 示例和文档。
