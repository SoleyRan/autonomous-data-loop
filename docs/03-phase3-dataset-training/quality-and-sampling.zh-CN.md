# 质量统计与样本筛选

[English](quality-and-sampling.md)

## 质量检查

数据集版本冻结前，平台应执行轻量质量检查：

| 检查项 | 作用 |
|---|---|
| 缺失标签检查 | 避免样本没有有效最终标签 |
| 时间戳映射检查 | 确保样本可以映射回来源 MCAP 数据 |
| 类别分布检查 | 发现严重类别不均衡 |
| 划分泄漏检查 | 避免近重复样本同时出现在 train/val/test |
| 传感器可用性检查 | 确保必要传感器流存在 |
| 标签 schema 检查 | 确保标签使用预期的统一格式 |

## 样本筛选维度

建议筛选维度：

- 时间范围。
- 车辆或设备别名。
- 事件或探针类型。
- 目标类别。
- 场景标签。
- 传感器类型。
- 标签版本。
- 标注置信度或质检状态。

## 划分策略

首版可以使用确定性哈希：

```text
split_key = hash(source_mcap_id + frame_timestamp_ns)
```

这样重复运行时划分保持稳定。后续版本可以加入场景感知划分，降低数据泄漏并提升评测公平性。
