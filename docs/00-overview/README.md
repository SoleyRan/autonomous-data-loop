# Overview

[简体中文](README.zh-CN.md)

This section introduces the background, goals, system boundary, and staged evolution of the autonomous data loop project.

## Key Points

- The project targets general autonomous driving data loop scenarios, from vehicle-side collection to platform-side data production and model iteration.
- The system starts from vehicle-cloud data upload and evolves toward annotation, dataset production, training, evaluation, and feedback-driven data collection.
- The repository is a sanitized technical portfolio and does not include proprietary production code or confidential data.
