# 开发计划

[English](development-plan.md)

## 建议工作流

| 工作流 | 输出 |
|---|---|
| 训练任务模型 | 训练任务、配置、状态、日志、产物和指标表 |
| 数据集消费 | 读取阶段三冻结后的数据集 manifest |
| 调度集成 | 将训练任务提交到本地、容器或集群运行环境 |
| 指标采集 | 保存总体、类别、场景和划分指标 |
| 模型注册 | 注册模型版本和模型产物 |
| 模型对比 | 对比基线模型和候选模型指标 |

## 推荐里程碑

| 里程碑 | 目标 |
|---|---|
| M1 | 可创建训练配置和训练任务 |
| M2 | 任务可消费数据集 manifest 并产出 mock 模型产物 |
| M3 | 指标可保存和对比 |
| M4 | 可基于配置、数据集和指标生成模型卡片 |
| M5 | 注册模型可进入阶段五评测 |

## AI 辅助研发机会

- 生成训练配置 schema。
- 生成任务状态机和 mock 调度器。
- 构建指标采集器和对比器。
- 生成模型卡片。
- 生成文档和评审清单。
