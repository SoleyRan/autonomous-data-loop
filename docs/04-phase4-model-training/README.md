# Phase 4: Model Training

[简体中文](README.zh-CN.md)

Phase 4 is planned to connect versioned datasets to perception model training, model registry, metric tracking, and data-to-model traceability.

## Planned Scope

- Training dataset selection.
- Training task orchestration.
- Training configuration management.
- Model artifact registry.
- Metric tracking and comparison.
- Traceability from model versions back to datasets and labels.
