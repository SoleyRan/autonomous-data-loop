# Development Plan

[简体中文](development-plan.zh-CN.md)

## Suggested Workstreams

| Workstream | Output |
|---|---|
| Feedback case model | Case, error type, scenario tag, lineage, and status tables |
| Requirement service | Convert grouped cases into scenario data requirements |
| Probe rule planner | Generate rule proposals from requirements |
| Collection tracking | Track new data returned from targeted collection |
| Outcome tracking | Link new data to later labels, datasets, models, and reports |
| Governance dashboard | Monitor duplicate, expired, and low-value requirements |

## Recommended Milestones

| Milestone | Target |
|---|---|
| M1 | Failed cases can be imported and grouped |
| M2 | Data requirements can be created from grouped cases |
| M3 | Probe rule proposals can be generated |
| M4 | New collected data can be linked back to feedback requirements |
| M5 | Outcome reports can show whether the loop improved |

## AI-Assisted Development Opportunities

- Group failed cases by scenario and error type.
- Generate probe rule proposals.
- Summarize feedback loop outcomes.
- Detect duplicate requirements.
- Produce review notes for high-impact rule changes.
