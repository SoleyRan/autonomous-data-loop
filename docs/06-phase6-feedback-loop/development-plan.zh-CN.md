# 开发计划

[English](development-plan.md)

## 建议工作流

| 工作流 | 输出 |
|---|---|
| 回灌 case 模型 | case、错误类型、场景标签、血缘和状态表 |
| 需求服务 | 将聚合 case 转化为场景数据需求 |
| 探针规则规划 | 基于需求生成规则建议 |
| 采集跟踪 | 跟踪定向采集返回的新数据 |
| 结果跟踪 | 将新数据关联到后续标签、数据集、模型和报告 |
| 治理看板 | 监控重复、过期和低价值需求 |

## 推荐里程碑

| 里程碑 | 目标 |
|---|---|
| M1 | 可导入并聚合失败 case |
| M2 | 可基于聚合 case 创建数据需求 |
| M3 | 可生成探针规则建议 |
| M4 | 新采数据可回连到回灌需求 |
| M5 | 结果报告可展示闭环是否改善 |

## AI 辅助研发机会

- 按场景和错误类型聚合失败 case。
- 生成探针规则建议。
- 总结回灌闭环结果。
- 检测重复需求。
- 为高影响规则变更生成评审说明。
