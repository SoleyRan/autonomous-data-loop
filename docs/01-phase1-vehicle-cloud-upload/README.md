# Phase 1: Vehicle-Cloud Data Upload

Phase 1 focuses on building the first reliable data path from vehicle-side collection to cloud/platform-side ingestion and playback verification.

## Scope

- Metadata and probe rule adjustments.
- MCAP recording and package upload.
- Compression and upload verification.

- Platform-side playback evidence.
