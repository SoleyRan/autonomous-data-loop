# Phase 5: Automated Test and Evaluation

[简体中文](README.zh-CN.md)

Phase 5 is planned to evaluate perception software and model versions using replayed MCAP data, ground-truth labels, SOC/Xavier execution, and structured test reports.

## Planned Scope

- Select labeled MCAP assets.
- Select perception software and model versions.
- Replay MCAP data to the target runtime.
- Compare perception outputs with labels.
- Generate evaluation reports.
