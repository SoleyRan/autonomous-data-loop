# 开发计划

[English](development-plan.md)

## 建议工作流

| 工作流 | 输出 |
|---|---|
| 评测实体模型 | 任务、运行配置、预测、指标、报告、失败 case 表 |
| 数据集与模型绑定 | 解析前序阶段的数据集版本和模型版本 |
| 回放 Worker | 从 MCAP 或派生样本执行回放 |
| 运行适配器 | 启动并监控目标感知运行环境 |
| 指标服务 | 将预测结果与统一标签对比 |
| 报告服务 | 生成报告和回灌候选 |

## 推荐里程碑

| 里程碑 | 目标 |
|---|---|
| M1 | 可基于数据集和模型版本创建评测任务 |
| M2 | 回放和运行适配器可产出预测记录 |
| M3 | 指标服务可生成摘要和失败 case |
| M4 | 评测报告可导出为 JSON/Markdown |
| M5 | 失败 case 可进入阶段六回灌流程 |

## AI 辅助研发机会

- 生成评测任务状态机。
- 生成指标对比脚本。
- 生成报告模板。
- 分析失败 case 和日志。
- 产出回归摘要和发布评审说明。
