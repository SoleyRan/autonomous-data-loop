# Feedback Probe Rule Builder Demo

[简体中文](README.zh-CN.md)

This demo converts feedback cases into a scenario data requirement and a probe rule proposal.

It demonstrates the Phase 6 idea: failed cases should not stop at reports. They should become targeted data collection work.

## Run

```powershell
python build_probe_rule.py `
  ..\..\examples\feedback\feedback-case.example.json
```
