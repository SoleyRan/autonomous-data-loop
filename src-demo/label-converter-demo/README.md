# Canonical Label Converter Demo

[简体中文](README.zh-CN.md)

This demo converts a simplified canonical label JSON file into KITTI-like text lines.

It is meant to demonstrate the adapter pattern used in Phase 2. It is not a complete KITTI or nuScenes converter.

## Run

```powershell
python canonical_to_kitti.py ..\..\examples\label-format\canonical-label.example.json
```
